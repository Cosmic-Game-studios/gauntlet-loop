# Arena

Open `index.html` via any static server (e.g. `npx http-server game`), click PLAY.

Controls: mouse look (pointer lock), WASD move, Shift sprint, Space jump, LMB fire, R reload, 1/2 or mouse wheel switch weapon (1 rifle, 2 shotgun), Esc pause.
Survive 5 waves of Rushers (melee) and Shooters (ranged green plasma bolts - dodge them).
Settings (mouse sensitivity, master volume) apply live from the main or pause menu.
